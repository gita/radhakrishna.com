## 1. Search Landscape Overview

The Radha-Krishna universe splits into **five demand engines**, each with a different intent profile and a different set of weak incumbents:

| Engine                                               | Intent                               | Volume                | Monetization/UX pull    | Incumbent quality                       |
| ---------------------------------------------------- | ------------------------------------ | --------------------- | ----------------------- | --------------------------------------- |
| **Story / mythology Q&A**                            | Informational                        | Very high, evergreen  | Ad + dwell time         | Weak (Quora, florist/art blogs)         |
| **Devotional practice** (mantra/aarti/bhajan/stotra) | Informational + audio-transactional  | High, ritual-driven   | Audio/app, high loyalty | Fragmented (ISKCON locals, lyric blogs) |
| **Images / wallpaper / quotes / status**             | Visual / download-transactional      | Massive, mobile-first | Pinterest/IG, ad farms  | Very weak (spam image farms)            |

| **Temples & pilgrimage cities**                      | Informational + travel-transactional | High, steady          | Tour/taxi lead-gen      | Weak-medium (taxi blogs)                |

**Strategic read:** We win by being the **single authoritative, scripture-sourced, schema-marked, beautifully designed hub** that covers _all five_ engines with internal linking between story ↔ mantra ↔ temple ↔ festival ↔ image. No incumbent does this. ISKCON is authoritative but fragmented across dozens of local chapter sites with dated UX. Wikipedia is authoritative but dry and unshareable. The image farms are shareable but content-worthless. We occupy the empty center.

## 3. Intent Classification (Informational vs Visual vs Transactional)

- **Informational (our core strength — build depth + schema):** Almost all of Clusters A, B, E; the "meaning/lyrics/history" half of C, F, G. This is where quality + sourcing + FAQ/Article schema wins featured snippets and AI-Overview citations. **~60% of total query volume, ~80% of winnable authority.**
- **Visual / download (Cluster D + image-half of story/festival/temple):** Highest raw volume, lowest content moat. Win via **original, high-resolution, tastefully-designed, downloadable image sets with proper alt text, ImageObject schema, and Pinterest/IG distribution.** Google Images + Pinterest are the battlegrounds, not classic blue links.
- **Transactional — audio/app (bhajan mp3, aarti audio, "app"):** Saregama, JioSaavn, and App Store apps own this. We don't out-license music, but we **can** own _"[stotra] lyrics + meaning + embedded audio + text-to-follow"_ pages, which are informational-transactional hybrids the audio platforms do poorly. Optional future: a PWA "daily Radhe Radhe / aarti" app.
- **Travel-transactional (temple timings, tour, how-to-reach):** Currently owned by taxi/tour lead-gen blogs with thin, keyword-stuffed content. We beat them on _accuracy + design + trust_, and can monetize later via affiliate/tour partners without the spam.

### 4.2 The exploitable gaps (our wedge)

1. **No unified authority hub.** The space is fragmented — no single site owns story + practice + festival + temple + image with consistent quality. We build the hub.
2. **No sourcing.** 90% of ranking Q&A pages cite _nothing_. We cite Bhagavata Purana, Brahma Vaivarta Purana, Gita Govinda, Garga Samhita, Padma Purana with chapter references. Instant E-E-A-T + AI-Overview citability.
3. **No schema.** Almost nobody uses Article, FAQPage, ImageObject, Event (festivals), Place (temples) schema properly. Easy featured-snippet + rich-result capture.
4. **Ugly, ad-choked, slow UX.** The incumbents (esp. image farms, taxi blogs) are hostile mobile experiences. A fast, clean, reverent design is a differentiator _and_ a ranking factor (Core Web Vitals).
5. **Contradiction without resolution.** "Did they marry?" "How did she die?" — incumbents pick one thin answer. We present the _scripture-by-scripture_ view, which is both more truthful and more comprehensive (owns the long tail of nuance queries).
6. **No bridge between intents.** Nobody links "why didn't they marry" → the philosophical meaning → a shareable quote card → the Radhashtakam → Barsana temple. Our internal linking compounds authority and dwell time.
7. **Visual quality vacuum.** Every image result is a spam farm. Original, licensed/AI-crafted, tasteful, fast-loading galleries with real metadata win Google Images and Pinterest simultaneously.

## 5. Where Visual / Image Demand Is Highest

**Image demand is arguably the single largest volume bucket in the entire space** and the weakest incumbent field. Priority order:

1. **"Radha Krishna images / HD images / photos"** — Google Images primary; ranked by spam farms (photosnow, photosking). Winnable with original hi-res sets + ImageObject schema + fast CDN.
2. **"Radha Krishna wallpaper (4k / mobile / desktop)"** — download intent; needs true multi-resolution downloads (farms fake this).
3. **"Radha Krishna dp / WhatsApp dp / profile picture"** — square-crop, mobile-share; pairs with quote overlays.
4. **"Radha Krishna quotes (Hindi/English/love/sad)"** — text-on-image; **Pinterest + Instagram** are the discovery engines here as much as Google.
5. **"Radhe Radhe / good morning Radhe Radhe images"** — daily-share behavior, enormous recurring volume, extremely low competition quality.
6. **"Radha Krishna status / video status"** — short-video (needs Reels/Shorts + a status-download page).
7. **"Radha Krishna drawing / sketch / painting"** — Pinterest-native, art audience.

**Platform strategy:**

- **Google Images** — original assets, descriptive filenames, alt text, `ImageObject` + `license` schema, fast CDN, dedicated indexable gallery pages.
- **Pinterest** — highest-leverage off-site channel for quotes/wallpapers/art; vertical 2:3 pins, keyword-rich pin descriptions, boards per festival/deity. Pinterest itself frequently ranks in Google Images.
- **Instagram** — quote cards, festival posts, Reels for "status"; drives brand + returns.
- **On-site** — every story/festival/temple page ships with a matching, downloadable image set (kills the "images" query and the "story" query with one page).
